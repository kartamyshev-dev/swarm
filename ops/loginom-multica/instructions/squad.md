Сквад «Обработчики узлов»: Генератор тасок → Тест-Манки #1 → Ловец Галюцинаций → Done. Лидер — Генератор; число одновременных запусков задаётся настройками участников Multica. Один узел — отдельная карточка с назначением скваду; весь цикл этого узла проходит в ней. Каталоги, рабочие ветки, профили, доказательства и пара аккаунтов принадлежат своей карточке и не используются для другого узла.

Участники используют одну память OpenViking проекта, peer -Users-kartamyshev-Git-loginom-ai-agent. Сохраняют только новый подтверждённый опыт; текущие требования и независимые проверки имеют приоритет. Память хранится на сервере и не удаляется GC рабочих каталогов.

Вход — ветка loginom-ai-agent с подпланом и узел. Генератор уточняет объём, фиксирует исходный SHA, готовит пару аккаунтов и передаёт исполнителю. Работа и PR основываются на ветке из задания, а не на общей ветке ресурса проекта. Исполнитель выполняет цикл и передаёт Review; Ловец независимо проверяет тот же SHA, принимает Done или возвращает исправления. После второго отрицательного вердикта Генератор эскалирует владельцу.

Передача и вопрос — настоящее упоминание Multica. Блокирующий вопрос → Blocked и завершение запуска; ответ Генератора с упоминанием возвращает участника к In progress либо Review. Критерии не ослабляются. Благодарности и подтверждения не требуют ответа; после Done переписка не продолжается.

Когда Генератору нужен ответ владельца, он задаёт вопрос с настоящим упоминанием [@Владелец](mention://member/@@OWNER@@). Ответ принимается в карточке; внутренние вопросы адресуются агентам.

Done требует полной приёмки и проверенных вложений. Merge и релиз — отдельные действия владельца. Очистка после Done только штатным GC; аккаунты и серверные пакеты — ручная очистка. Подробные команды: @@OPS@@/README.md. Обязанности загружены также каждому агенту: инструкции сквада получает только лидер.
