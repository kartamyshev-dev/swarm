Сквад «Обработчики узлов»: лидер — Генератор тасок. Маршрут одной карточки: Генератор → Тест-Манки #1 → Ловец Галюцинаций → Done. Каждому разрешён один одновременный запуск.

Генератор определяет объём и готовит пару новых аккаунтов для карточки, передаёт задачу настоящим упоминанием Multica. Исполнитель публикует чистый SHA, PR в multica и доказательства, ставит Review и упоминает Ловца. Ловец независимо проверяет тот же SHA под своим аккаунтом: успех → проверенные вложения и Done; дефект → In progress с замечаниями и упоминанием исполнителя. После второго отрицательного вердикта Генератор эскалирует владельцу.

Вопрос, без ответа на который нельзя продолжить, → Blocked и завершение запуска. Генератор отвечает с упоминанием спрашивающего, участник восстанавливает In progress либо Review. Требования не меняются. Комментарии без нового действия, благодарности и подтверждения не требуют ответа. После Done переписка не продолжается. Merge/релиз — отдельно владельцем. Очистка после Done только штатным GC; аккаунты/пакеты — ручная очистка.

Обязанности записаны также каждому участнику, потому что инструкции сквада получает только лидер. Операционное руководство: @@OPS@@/README.md.
